# 🦌 Lundstulen jaktlag – posttrekning

Trekk hvem i Lundstulen jaktlag som skal sitte på hvilken post – uten gjentakelser.

**Åpne appen:** https://vivonxt.github.io/jaktlagets-navnetrekker/

Skriv inn én jeger per linje, trykk «Klar til trekning» og trekk ett og ett navn. Resultatet kan kopieres og deles. På mobil kan siden legges til på hjemskjermen og brukes som en app.
