# 🦌 Jaktlagets navnetrekker

Trekk tilfeldig rekkefølge på jegerne i jaktlaget – uten gjentakelser.

**Åpne appen:** https://vivonxt.github.io/jaktlagets-navnetrekker/

Skriv inn én jeger per linje, trykk «Start trekning» og trekk ett og ett navn. Resultatet kan kopieres og deles. På mobil kan siden legges til på hjemskjermen og brukes som en app.
